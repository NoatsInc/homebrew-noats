# Noats Homebrew tap

Homebrew tap for [Noats](https://noats.ai/), local-first meeting notes for
macOS with on-device transcription and dictation.

## Install

```sh
brew install --cask noatsinc/noats/noats
```

`brew tap noatsinc/noats` first is optional; the three-part name taps
implicitly.

## Requirements

- Apple Silicon (arm64)
- macOS 14.2 (Sonoma) or later

## Updates

Noats updates itself in-app, and the cask declares `auto_updates true` so
`brew upgrade` will not fight the built-in updater. Both paths track the same
release feed, so a brew install and an auto-update always agree on what a
version is.

## Uninstall

```sh
brew uninstall --cask noats        # remove the app
brew uninstall --cask --zap noats  # also remove settings and local data
```

`--zap` removes only Noats' own data. The speech-model cache at
`~/Library/Application Support/FluidAudio` is shared with other apps and is
deliberately left alone.

## About this tap

`Casks/noats.rb` is generated by the Noats release pipeline: every release
rewrites `version` and `sha256` against the published, signed and notarized
DMG and pushes the result here. Please do not open pull requests against the
cask file; for anything else, reach us at [noats.ai](https://noats.ai/).
